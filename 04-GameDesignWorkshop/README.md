## 学习方法建议

1. **每章读完**：填对应笔记里的一句话、核心概念、关键洞察、个人思考。
2. **做书里的练习**：Fullerton 把练习当主路径，不是附录。尤其 Exercise 1.1（自己当试玩者）和第 2 章「想一款游戏再拆」。
3. **PDF 只放本机、不进 git**：`04-GameDesignWorkshop/game-design-workshop.pdf` 已 gitignore。公开站不挂这本书的扫描件。笔记用自己的话转述机制。
4. **旧版访谈**：纸书腾给新声音，旧 Designer Perspectives 在 [官网](https://www.gamedesignworkshop.com/designer-perspectives)。
