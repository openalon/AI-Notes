六组骨架：

1. **总体控制面**：prompt 装配、query loop、tool/permission、context、recovery、multi-agent、team hooks 围成一张图
2. **Query Loop 主循环与恢复分支**：输入治理 → 流式模型 → 工具 / 恢复 / 停止矩阵
3. **Tool Batch Ordering 与 StreamingToolExecutor**：并发分批、顺序回放、中断与 synthetic result
4. **Context Sources 与 Compact Rebuild**：CLAUDE.md / memory / session memory / compact 重建工作语义
5. **Coordinator-Worker 与 Verification Separation**：research / impl / verify 分容器，synthesis 不可外包
6. **团队治理图**：CLAUDE.md、approval、skill、hook、基线复盘 vs 高阶审计

## 关键洞察

图不是装饰。它们把「状态机」从口号变成可指认的边和节点：哪里分叉、哪里熔断、哪里必须补账。读笔记时若某章觉得抽象，对着对应图看一遍会快很多。
