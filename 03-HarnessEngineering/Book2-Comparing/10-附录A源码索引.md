## 一句话

这份索引不是源码副本，只说明各章判断依据哪些文件。作用是把比较钉在模块位置上，而不是承诺提供实现正文。

## 核心概念

边界与 Book 1 附录 C 相同：仅保留必要的工程性引用、模块定位和结构分析，不附 Claude Code / Codex 实现正文，也不大段转录源码。

## 关键洞察

Claude Code 的依据几乎都围着 `query.ts` 和工具编排转；Codex 的依据从 `core/src/lib.rs` 散到 instructions、execpolicy、thread、hooks 多个 crate。文件布局本身就是第 7 章的论据：一个把秩序压进运行时主文件，一个把秩序拆成可组合模块。

## 个人思考

对照 Book 1 附录 C：那边只列 Claude Code。这边多出来的 Codex 路径，正好是「显式控制面」这句话的落点。读章时若觉得某句判断飘，先回这张表看它钉在哪个文件上，不要凭产品名脑补。
