## 一句话结论

Agent 时代真正稀缺的不是“会调模型”，而是一套可复用的提问方式：**把问题问清、把知识学透、把路径依赖拆开、把决策做成可证伪实验，并持续认识自己。** Prompt 不是过时技巧，而是思考底座。

## 核心观点

### 1. Agent 再强，人仍然要知道自己在问什么、要去哪

卡兹克（@Khazix0918）在 2026-08-21 这篇长文里，把过去几年自己真正常用的 Prompt 收成 12 个模板，分成五个场景：**问清问题、学习、解决问题、决策、认识自己**。

文章的反常识不在“再发一套万能提示词”，而在这个判断：

- Skill、Agent、自定义命令会越来越强
- 但大多数人日常面对的，仍是混乱的问题、半生不熟的概念、路径依赖的方案、拍脑袋的选择
- 这些环节里，**怎么问、怎么核、怎么选、怎么看自己**，比“接了哪个 Agent”更底层

作者收束得很硬：AI 越像神明，人仍要知道自己想要什么、想去往何方。这才是 Prompt 最后的意义。

这些模板不依赖特定产品：把 `【】` 换成自己的材料，丢进对话式 AI 或 Agent 即可。它们面向的是还没搭个人命令系统、但仍要高质量思考的人。

### 2. 问清问题：先别急着要答案，先把问题问成“真问题”

#### 1. 苏格拉底式提问

用法：问题还糊的时候，先别让模型给方案。

机制很克制：

- 最多 6 轮，一次只问一个问题
- 把事实、解释、价值和目标拆开
- 可以提前停，不必凑满轮次
- 最后对照：你原来问的 vs 真正该问的

它解决的是 Agent 时代最常见的失败模式：**把一个没想清楚的问题，交给一个执行力很强的系统。** 执行越强，跑偏越贵。

### 3. 学习：不是让 AI 再讲一遍，而是建立可检验的理解

#### 2. 双层解释法

同一概念先给生活化版本，再给专业版本，并标出对应关系、常见误解和 3 个自检问题。适合“听过但没真懂”。

#### 3. 反向拆解

拿一个已经做得好的成品（文案、页面、方案、产品）倒着拆：结构、关键选择、可迁移规则、操作清单、小练习。学的是**别人已经验证过的选择**，不是抽象定义。

#### 4. 横纵分析法

纵向看历史（它为什么会变成现在这样），横向看同类（别人怎么选、代价是什么），再判断未来路径。适合陌生领域的系统研究，通常要配合深度研究 / 长上下文，输出带出处的长报告，而不是一段摘要。

#### 5. 事实核查

把一段话拆成事实、推论、价值判断，分别核来源、标可信度、找逻辑漏洞。适合核对 AI 输出和二手观点。模型越流畅，这项越必要。

这四个学习模板共享一个原则：**理解必须能被解释、被拆开、被对照、被证伪。** 否则只是把幻觉写得更长。

### 4. 解决问题：打断“按惯例生成”，从硬事实重推

#### 6. 专家会诊

不是伪造三个名人站台，而是找三个**互补透镜**（例如机制、约束、用户），各自分析、互相质疑，再合成方案、风险和退出条件。

#### 7. 第一性原理

作者把它叫成接近“万能 Prompt”的那一个：先列出硬事实、隐藏假设、目标和约束，放下行业惯例，重新推导路径。最短用法甚至是在任何问题后面补一句：**从第一性原理出发。** 它专门打断模型最爱的类比续写。

#### 8. 跨领域借解

把问题抽象成底层结构，从至少三个远领域借机制，再挑一个便宜、可逆的试验。用来打破“只能在本行业找答案”的窄视野。

三者合在一起，是在对抗 Agent 的默认行为：用训练数据里的常见解，快速给你一个看起来很专业的方案。

### 5. 决策：先钢人两边，再用最小实验代替空想

#### 9. 双向钢人论证

对两个选项都做最强支持和最强反对，找出真正的分歧点和那个可能翻盘的问题，再判断。禁止先站队再找理由。

#### 10. 最小实验

先找到“一旦被证伪就会改变决定”的那个假设，设计低成本、可逆、有继续/停止条件的短实验，并给出明天就能做的第一步。

决策模板的核心不是更会辩论，而是：**把不可逆选择，压成可逆验证。**

### 6. 认识自己：Agent 无法替你回答“你要去哪”

#### 11. 挖掘隐藏天赋

多轮追问童年胜任区、不费力却被夸的事、能量涨落、嫉妒对象等，最终整理成一份较长的《个人天赋使用说明书》：优势、阴影、能量地图、职业建议和 30 天实验。

#### 12. 人生设计术

基于斯坦福 Life Design / Odyssey Plan：看清健康、工作、娱乐、爱的仪表盘，生成三个差异足够大的五年版本，再落到可做的原型行动。输出是一份人生设计蓝图，不是一句鸡汤。

后两个交互更长，需要真实回答，不适合当一次性指令。作者把它们放在最后，是因为前面十个都在优化“怎么想清楚一件事”；这两个在问：**你究竟是谁，以及你愿意过哪一种五年。**

### 7. 这 12 个 Prompt 真正共享的设计纪律

把模板当收藏夹会用错。它们反复出现的约束更值得记：

- **一次只推进一层**：先澄清，再解释，再方案，再决策
- **把事实、解释、价值、目标分开**，避免混成一句正确的空话
- **输出必须可执行**：对照表、清单、实验、退出条件，而不是感想
- **给模型停手权**：问题已清就可以结束，不必把轮次凑满
- **人要提供原材料**：长上下文再强，也替代不了你自己的事实、约束和偏好

第三方仓库（如 `xiaolouJB/prompt-toolkit`）把这套模板按文件拆开，并标 CC BY-NC 4.0。仓库是再包装，不是原作者的官方产品；原意仍是“可直接粘贴的思考脚手架”，不是又一套要安装的 Skill。

## 核心脉络

### 这篇文章真正的论证链路

1. Agent / Skill 降低了“执行”的成本，但没有降低“想清楚”的成本
2. 大多数失败不是模型不够强，而是问题没问清、概念没学透、方案被惯例绑住、决策不可证伪、方向不属于自己
3. 所以作者不给新工具，而给 5 个场景、12 个可复用提问结构
4. 这些结构的共同点是：拆分层级、强制核验、把空谈变成实验
5. 最后仍要回到人：AI 可以放大思考，但不能替你选择命运

## 对实际工作的启发

### 对个人使用

- 问题还糊时，先跑苏格拉底，再让 Agent 开工
- 学新概念时，要求双层解释 + 自检题，而不是“用大白话再说一遍”
- 面对“大家都这么做”的方案，强制走第一性原理或跨领域借解
- 二选一时，先双向钢人，再设计一个能打脸自己的最小实验
- 把常用 Prompt 做成个人命令或 Skill 可以，但先保证自己真的理解它在约束什么

### 对 Agent / 工程工作流

- Prompt 和 Harness 不互斥：Harness 管执行环境，这 12 个管思考入口
- 在 `CLAUDE.md` / 自定义命令里，更该沉淀的是这些**提问纪律**，而不是又一段客套人设
- 高风险任务前加两道闸：事实核查、最小实验；高发散任务前加两道闸：第一性原理、专家会诊

### 对决策与自我管理

- 不要把人生选择直接丢给模型排序
- 用 Odyssey 的三个五年版本，强迫自己看见“默认人生”之外的路径
- 天赋说明书的价值不在标签，而在 30 天可做的小实验

## 我认为最值得记住的三句话

- **Agent 负责跑，Prompt 负责让人知道自己在跑什么。**
- **好 Prompt 不是更会说话，而是把事实、解释、价值和目标拆开。**
- **AI 越像神明，人越要知道自己想要什么、想去往何方。**
