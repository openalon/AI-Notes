## 一句话

**图不是「贴一张让模型看」，是另一种要钉形状的输入：怎么传、什么分辨率、提示写在图上还是字上、细节不够就给放大镜。** 幻灯和扫描件尤其不能靠传统 OCR 交差。

## 核心概念

### 传图：URL 就能进 Messages API

`getting_started_with_vision.ipynb` 是最小路径。后面所有技巧都建立在「图已经是一条 content block」。

### 视觉也吃传统 prompt 工程

`best_practices_for_vision.ipynb`：数狗会数错，加角色和约束就对了。还可以 **把提示画在图上**（箭头、高亮、图内问题）。few-shot 用图当例子（读时速表单位、认裤型）。超长收据切成多图一次喂。视觉 few-shot 不是总有效，但值得试。

### 图表和幻灯：算术和颜色是坑

`reading_charts_graphs_powerpoints.ipynb`：图表优先走 PDF + vision（当时 `pdfs-2024-09-25` beta，模型限制以 notebook 为准）。两个坑：算术偶发错 → 给计算器工具；靠颜色分组的图 → 先让模型报 HEX 再读数。复杂图可先「描述每一个数据点」（视觉版 CoT）。

幻灯：PyPDF 抽文本会丢掉真正有信息的图。整本 PDF 直接喂有页数上限（当时 100 页），且多模态 PDF 进 RAG embedding 会惹麻烦。替代：逐页叙述，当前页 + 已有叙述，得到可检索的文本稿。

### OCR 是「按你的形状抽」，不是认字

`how_to_transcribe_text.ipynb`：优势是指定抽什么（只要答案里的代码、手写处方、表格单）。再往上是文档 QA，以及非结构 → JSON（接回第 1 章 schema）。

### Zoom：固定分辨率看不清时，给 lean-in

`crop_tool.ipynb` 是本章最硬的工程。Claude 按约 28×28 patch 看图，细标签、紧挨的线在这个分辨率下 **prompt 救不回来**。zoom 工具：模型输出像素框，你从 **原图全分辨率** crop 并放大再回传。

必须先按文档的 `resized_size()` 预缩放，模型吐的坐标才和你手里的图 1:1。Chartography（100 题）：Fable 5 29% → 73%（+44）；Sonnet 5 13% → 44%（+31）。演示题 Widget-A/E：无工具 40 次里 36 次错，有工具 40/40。代价：每 zoom 重送对话 + 放大作物，Fable 5 约 $0.08 → $0.95 / 题。长 thinking 轮要注意 stop-reason，避免静默截断。

同一模式适用密文档、UI 截图、原理图、扫描表单、标签照片。视觉叠工具见 [[03-工具调用]] 的 `vision_with_tools`。

### 语音是进出适配器

`third_party/Deepgram/prerecorded_audio.ipynb`、`ElevenLabs/low_latency_stt_claude_tts.ipynb`：录音 → 文本 → Claude → 语音。能力边界在 STT/TTS 厂商，Claude 仍吃文本。细节见 [[12-集成与第三方]]。

对照 recipe：

| 路径 | 钉的是什么 |
|---|---|
| `multimodal/getting_started_with_vision.ipynb` | 图怎么进 Messages API |
| `multimodal/best_practices_for_vision.ipynb` | 角色、图内提示、few-shot、切图 |
| `multimodal/reading_charts_graphs_powerpoints.ipynb` | 图表算术 / 颜色；幻灯改叙述再检索 |
| `multimodal/how_to_transcribe_text.ipynb` | 按形状抽，不按「认全页」 |
| `multimodal/crop_tool.ipynb` | 给模型一把放大镜 |
| `third_party/Deepgram/prerecorded_audio.ipynb` | 录音进文本再交给 Claude |
| `third_party/ElevenLabs/low_latency_stt_claude_tts.ipynb` | 低延迟语音进出 |

## 关键洞察

多模态的失败经常被说成「模型看不懂」。cookbook 的诊断更具体：分辨率不够、颜色没先标定、算术没工具、幻灯当纯文本切了。zoom 把「看」收成工具环——和第 3 章同一逻辑：模型提出需要，你的工具改变它能看见的世界。

准确率涨幅很大，账单也是。视觉工具是产品决策，不是默认打开的滤镜。
