## 一句话

**先规定模型交什么，再谈它聪不聪明。** 输出契约不是文风：能被程序吃掉、能核对出处、闭集可评、摘要有尺子、审核不当场即兴。做不到这些，后面的 RAG、工具、agent 都只是把噪声放大。

## 核心概念

### 没有 JSON Mode，只有形状约束

Claude 没有 constrained sampling 的正式 JSON Mode。`misc/how_to_enable_json_mode.ipynb` 给的是工程补丁：prefill `{` 砍掉前言；stop sequence 砍掉后话；复杂多对象用 XML 标签包起来再 regex 抽。prefill 的代价写得很清楚——模型没法在 JSON 前做 Chain of Thought，智力会掉一截。

真正硬的形状不在散文里。`tool_use/extracting_structured_json.ipynb` 把摘要、NER、情感、分类做成 **tool schema**：模型只能往 `input_schema` 里填。未知键才退回开放 schema + 提示词。对照：Book 1 把 prompt 当控制平面；这里 schema 才是输出平面。

### Citations 是产品功能，不是「请引用原文」

`misc/using_citations.ipynb`：API 级 citations 比 prompt 级引用更准、更省 output token（不用把整段原文再吐一遍），也不会引用你没给过的文档。三种文档对应三种粒度：

| 文档 | 引用形状 |
|---|---|
| 纯文本 | 字符区间（自动按句切） |
| PDF | 页码（1-indexed） |
| custom content | 你自己定的 chunk |

`context` 字段能喂元数据、使用说明、contextual retrieval 的补丁，但 **不可被引用**。这是刻意的：模型可以用，用户核对时看不到。PDF 只回页码，高亮要自己用 PyMuPDF 对 cited_text。

### 分类是闭集，准确率靠检索和推理，不靠「再写一遍 prompt」

`capabilities/classification/guide.ipynb` 用保险工单 10 类，把 70% 推到 95%+。路径不是换更大模型，是：类定义写清楚 → 用向量库捞相似训练样本进 prompt → CoT。LLM 适合规则复杂、样本少、还要解释的分类；评测必须有独立 test set，不能靠感觉。

### 摘要没有客观最优，所以必须自带评测

`capabilities/summarization/guide.ipynb` 拿 SEC 转租协议当样本。裸摘要每次结构都变，没法进流水线。进阶是：guided / 领域字段、meta-summarization、summary-indexed RAG。评测承认主观：ROUGE 不够，promptfoo + 任务标准才像生产。assistant prefill `<summary>` + stop `</summary>` 是第 1 章反复出现的形状手法。

### 审核：早期过滤器 vs 政策编译器

两代做法不要混：

- `misc/building_moderation_filter.ipynb`：prompt 里写 ALLOW/BLOCK，返回一个词。适合论坛主题、快速闸门。CoT 和 few-shot 能抬准度，但同一内容两次跑可以给不同判决。
- `capabilities/content_moderation/guide.ipynb`：**Claude 永不判刑**。你写 extraction schema；Claude 把政策散文编译成带 scope 的 JSON 规则（validator 修到能过）；每条内容抽成 typed fields（含图）；无模型的 engine 出 verdict + 审计轨迹。政策改动变成可 diff 的规则版本，不是改一段 prompt。LLM assertion（「看起来不满 25 岁」）是规则语言里的模型字段，判决仍在 engine。

### 其余输出契约

- **Metaprompt**（`misc/metaprompt.ipynb`）：空白页启动器，不是最优 prompt。人必须验收。
- **前端审美**（`coding/prompting_for_frontend_aesthetics.ipynb`）：观感也是契约。默认审美是 Inter + 紫渐变 slop，要显式禁。
- **Fable 5 分类降级**（`fable_5_fallback_billing/guide.ipynb`）：`stop_reason: refusal` 时服务端落到 Opus 4.8，账单记一笔 credit。分类失败是产品路径，不是异常日志。
- **超长续写**（`misc/sampling_past_max_tokens.ipynb`）：`max_tokens` 截断后要有续采样协议，不能假装一次说完。

def visualize_raw_response(response):
    raw_response = {"content": []}

    print("\n" + "=" * 80 + "\nRaw response:\n" + "=" * 80)

    for content in response.content:
        if content.type == "text":
            block = {"type": "text", "text": content.text}
            if hasattr(content, "citations") and content.citations:
                block["citations"] = []
                for citation in content.citations:
                    citation_dict = {
                        "type": citation.type,
                        "cited_text": citation.cited_text,
                        "document_title": citation.document_title,
                    }
                    if citation.type == "page_location":
                        citation_dict.update(
                            {
                                "start_page_number": citation.start_page_number,
                                "end_page_number": citation.end_page_number,
                            }
                        )
                    block["citations"].append(citation_dict)
            raw_response["content"].append(block)

    return json.dumps(raw_response, indent=2)

def extract_prompt(metaprompt_response):
    between_tags = extract_between_tags("Instructions", metaprompt_response)

            "No <Instructions> block found in the response. "
            "Re-run the metaprompt cell, or inspect the response with pretty_print(message)."

```python
# Fable applies extra safety filters. With a fallback chain configured, the API
# retries blocked turns on the next model server-side. A stop_reason of "refusal"
# means the whole chain refused.

from anthropic import Anthropic

client = Anthropic()


def chat_turn(messages, max_tokens=1024):
    """One API call; the server handles the fallback."""
    return client.beta.messages.create(
        model=PRIMARY_MODEL,
        max_tokens=max_tokens,
        messages=messages,
        betas=[SERVER_SIDE_FALLBACK_BETA],
        fallbacks=[{"model": FALLBACK_MODEL}],
    )

with client.beta.messages.stream(
    model=PRIMARY_MODEL,
    max_tokens=1024,
    messages=[{"role": "user", "content": "Hello, world"}],
    betas=[SERVER_SIDE_FALLBACK_BETA],
    fallbacks=[{"model": FALLBACK_MODEL}],
) as stream:
    for event in stream:
        if (
            getattr(event, "type", None) == "content_block_start"
            and getattr(event.content_block, "type", None) == "fallback"
        ):
            fb = event.content_block
            fb = fb.model_dump() if hasattr(fb, "model_dump") else dict(fb)
            print(f"[switching: {fb['from']['model']} -> {fb['to']['model']}]")
    final = stream.get_final_message()

# Definitive per-turn check, same as non-streaming: usage.iterations also
# catches a stream served directly by the fallback model (no in-stream event).
if served_by_fallback(final):
    print(f"[fallback model served this stream: {final.model}]")

def stream_turn(messages, max_tokens=1024):
    with client.beta.messages.stream(
        model=PRIMARY_MODEL,
        max_tokens=max_tokens,
        messages=messages,
        betas=[SERVER_SIDE_FALLBACK_BETA],
        fallbacks=[{"model": FALLBACK_MODEL}],
    ) as stream:
        # Nothing streamed is ever discarded: after a mid-stream block, the
        # final message is partial + fallback block + continuation.
        final = stream.get_final_message()

    if final.stop_reason == "refusal":
        return final  # the whole chain refused
    text = "".join(b.text for b in final.content if b.type == "text")
    print(f"{final.model}: {text}")
    return final
```

## 关键洞察

这一章的共同动作是 **把自由生成收成可验收的形状**。JSON / tool schema 收程序接口；citations 收证据链；分类收标签集；摘要收评测集；政策编译收审计。跳过形状直接做 agent，你会在第 5、8、9 章用更贵的循环生产无法对账的文本。

和 [[02-Prompt是控制平面]] 对齐：控制平面管「能做什么」；输出契约管「交出来长什么样」。两边缺一，系统就只剩一次碰巧说对。

## 个人思考

读 Cookbooks 容易从「怎么让 Claude 更听话」入手。第 1 章纠正的是：听话之前先规定交卷格式。下一章检索会把「形状」扩到「从哪取证据」——citations 的 `context` 字段已经在给 contextual retrieval 留位置。
