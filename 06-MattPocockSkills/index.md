# Matt Pocock Skills

Matt Pocock [Skills For Real Engineers](https://github.com/mattpocock/skills) 的学习笔记。结构和语气对齐 [[00-Skills阅读导读]] 与 `05-ClaudeCookbooks`：一章一个约束，按工程依赖重排，不按上游 `engineering/` / `productivity/` 平铺。

来源：[GitHub](https://github.com/mattpocock/skills) · 文档：[aihero.dev](https://aihero.dev)

官方 `SKILL.md` 留在本机的 skills 仓库，**不拷进本库**。笔记只写机制、取舍和能带走的判断。

建议顺序：先第 1–4 章把「对齐、语言、主流程」钉住，再第 5–6 章谈反馈和设计，最后第 7–9 章落到规模、会话和评审。

## 本书在讲什么

不是 skill 说明书，也不是 25 个文件的目录拷贝。核心是：**GSD / Spec-Kit 那种「接管全过程」的框架拿走控制权；这套 skill 把工程纪律拆成可组合的小件，人决定走哪条路。** 上游按用途分桶；这本笔记按失败模式的修复顺序重排，让每一章对应一个你必须先想清楚的约束。
